# BE-IIS-HPP-2T1L-REVA

Raspberry Pi Device Tree overlays for the BE-IIS dual 10BASE-T1L HAT++ Rev.A,
based on the Analog Devices ADIN2111 two-port 10BASE-T1L switch.

The three overlay variants correspond to the HAT++ slot descriptors `I`, `II`,
and `III` supplied with this hardware. Build the sources in
`overlays/src/rpi/` using `make`.
